# Security Policy

## Supported Versions

We currently support the latest version of the dashboards and smart contract code.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

**Please do not open a public issue.**

Instead, contact us privately via X DM to @CryptoCT01 or email (if available in the future).

We will acknowledge your report within 48 hours and work with you to understand and resolve the issue.

## Scope

This security policy applies to:
- The HTML dashboards
- The Solidity smart contracts
- Any associated documentation

Thank you for helping keep this project secure.
